SCSS 미디어쿼리 믹스인을 활용해 Desktop, Tablet, Mobile 환경에 최적화된 반응형 레이아웃을 구현했습니다.

1.진행 기간:2025.10.02~ 2025.10.3 (2일)

2.개발 인원: FrontEnd 1인 (Solo Project)

3.사용 기술 스택: Language: JavaScript (ES6+) Styling: CSS Design & Tool: Figma, Git, GitHub, photoshop

4.Concept: 사이즈 별로 반응하는 웹사이트

5.디렉토리 구조 scssn=font,mixin,variation 같은 variables 파일 img=이미지 css=scss파일과 연결된 css파일

6.담당 역할  
[기획 및 디자인]
